# ServiceFind

A local service marketplace that connects customers with verified service providers.

---

## About
ServiceFind opens with a role selection screen where users choose to enter as a **Customer** or a **Service Provider** (Individual or Company). Customers can search and browse verified local professionals while providers can create and manage their profiles.

---

## Features
- Role selection on launch — Customer or Service Provider
- Service Provider types — Individual or Company
- Browse and search verified providers
- Kashmir-based service listings
- Account reset option

---


## Service Categories
Plumbing, Carpentry, Electrical, Photography, Travel, Cleaning, Baking, Tutoring, and more.

---

## How to Run
```bash
npm install
npm run dev
```

To future-proof local businesses by giving every skilled professional a trusted digital presence.
